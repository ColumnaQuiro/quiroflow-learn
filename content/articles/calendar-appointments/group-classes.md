A group class is a session with several places, such as Pilates or back school, given by one practitioner at a set time. On the calendar it takes a single block, but each place is an ordinary visit for that patient: it's charged, drawn from a bono or marked as a no-show just like any other visit.

## Before you start: an appointment type with places

Classes come from an appointment type with places. In **Settings › Appointment Types**, open the type (or create one, for example "Pilates suelo") and under **Group class** set the number of places (between 2 and 200). See [Appointment types and services](/articles/settings/appointment-types-and-services).

If there's none, the class dialog reminds you: "No appointment type is a class yet. Give one places in Settings › Appointment types."

## Put a class on the calendar

::help-video{clip="calendar--new-class" caption="Scheduling a weekly Pilates class"}
::

1. Click **New class** in the calendar's top bar.
2. Choose the **Class** (the appointment type), who gives it (**Given by**) and the **Room** (or **None**).
3. Set the **First day** and the **Time**.
4. Under **Weeks (same day and time)** say how many weeks it repeats (1 to 52), and under **Places** how many people fit.
5. Check the summary ("8 classes, every week until …") and click **Put it on the calendar**.

Each class shows as a block with the places taken and left ("6 places left"), or **Full** once it's full.

> **Good to know:** if the class is already on at one of those times, you'll see "That class is already on at one of those times."

## Add patients and take attendance

::help-video{clip="calendar--class-attendance" caption="Adding a patient to the class and marking who came"}
::

1. Click the class block. The panel shows how many places are taken ("2 of 8 places").
2. Under **Add to the class**, search for the patient and pick them. Once the class is full, the button changes to **Add to the waitlist**.
3. When the class is over, mark each person as **Came** or **Didn't come**, or click **Everyone came** (or **Everyone else came** if you've already marked someone).

Tap a name to charge their visit, draw it from a bono or undo it, as with any visit.

Patients can also book a place in a class through online booking.

## A class's waitlist

Each class has its own **Waitlist**: "When a place is cancelled it is offered to them in this order, with a link to take it." From the panel you can **Give the place** to someone directly or **Remove** them from the list.

## Change or cancel a class

- **Edit class** changes the **Day**, **Time**, who gives it, the **Room** and the **Places**. Tick **Tell the patients if the time changes** if you want them to know.
- **Cancel this class** cancels every place; the clinic's cancellation automations tell each patient. Confirm with **Cancel the class** or back out with **Keep it**.

> **Good to know:** a class place can't be booked as an individual visit from the normal booking panel. Add patients from the class's panel.

> **Good to know:** an **Unplanned absence** doesn't move class places: if whoever gives the class is off, change or cancel the class from its panel.
