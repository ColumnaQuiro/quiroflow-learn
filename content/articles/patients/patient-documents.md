## Sending a document

1. Select **New doc**.
2. Choose a template from the list -- common ones are consent forms, health history intakes, and treatment-specific variants (a pregnancy or pediatric health history, for example) -- or select **Blank document** to start from scratch.
3. Share it with the patient using **Open link** (opens it in a new tab yourself, useful if you're handing them a tablet in the waiting room) or **Copy link** (to send however you like -- WhatsApp, email, text).

The patient fills it out on their own device, no account or login required -- just the link. This makes it practical to send ahead of a first visit so intake is already done by the time they arrive, rather than filling out paperwork in the waiting room.

## Building your own templates

**Settings &rarr; Document Templates** is where these are created and edited -- write the content once (consent language, intake questions, signature fields) and reuse it for every patient instead of recreating it each time. Templates are shared across your whole account, so any staff member sending a document sees the same up-to-date list.

## Tracking status

Each document shows **Sent** until the patient submits it, then **Complete**. There's no reminder nag built in for an unsubmitted document -- if a patient hasn't completed one before their visit, it's worth a quick WhatsApp nudge using the same link. You can delete a document at any point if it was created by mistake or is no longer needed.
