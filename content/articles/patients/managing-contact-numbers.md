A patient can have more than one phone number on file -- common for a patient who's given you both a mobile and a home or work number. Find them on the patient's **Overview** tab under **Contact**, or select **Edit** on **Patient details** to manage them directly.

![Contact card showing a phone number with a WhatsApp badge](/screenshots/patient-overview.png)

## Adding or editing a number

In the edit view, each number has its own row with a country code dropdown and the number itself -- select the field to edit it directly, no need to delete and re-add it to fix a typo or update it. Select **Add** to add a second number, or the **X** next to a row to remove it.

## WhatsApp

Each number has a **WhatsApp** checkbox. Whichever number has it checked is the one QuiroFlow sends confirmations, reminders, and campaign messages to, and where inbound replies get matched back to this patient. If a patient has multiple numbers, make sure the right one is flagged -- only one should be marked as WhatsApp-enabled at a time, since that's what determines where automated messages actually land.

If a patient gives you a new number and you flag it for WhatsApp without removing the old one, both stay on file -- but only the WhatsApp-flagged one is used for messaging going forward, so the old number is effectively just a reference until removed.
